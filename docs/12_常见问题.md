# 12 常见问题

## 安装

**Q：命令提示「不是内部或外部命令」。**
刚装完的软件要**关掉终端重新打开**才生效。还不行就重启电脑。

**Q：winget 用不了。**
Windows 10 老版本可能没有 winget，去 Microsoft Store 装「应用安装程序」。也可以去各软件官网下载安装包。

**Q：pip 或 npm 下载很慢、超时。**
跟 AI 说「帮我换国内镜像源」。

**Q：Python 输出的中文是乱码。**
运行前先设 `$env:PYTHONIOENCODING="utf-8"`（PowerShell）。AI 一般会自己加。

## Claude Code

**Q：它停下来说某个操作被拦截了。**
这是安全机制，付费接口、删除文件这类操作会被拦。确认没问题的话：
- 输入 `/permissions` 放行；
- 或者照它给的命令，自己以 `!` 开头运行一次。

**Q：它提示用量到上限了。**
拍片消耗很大，建议用高一档的订阅。可以少开几个分身，或分几天做。

**Q：它好像卡住了、在原地打转。**
按 `Esc` 打断，说「停一下，告诉我现在卡在哪、试了什么」。

**Q：关了窗口，活还在吗？**
工程文件都在；正在跑的任务（渲染、出片等待）会停。重新打开 `claude --resume`，说「接着做」。

## 画面和渲染

**Q：渲染很慢。**
正常。自适应运动模糊在快速运动的帧上会算几百个子帧。
- 审片用缩略图和静帧，只有最终导出才渲整片。
- 只改了一段，就只渲那一段。

**Q：电脑越来越卡，内存被吃满。**
多半是预览服务器或 Chrome 没关干净。跟 AI 说「查一下什么进程在吃内存，把泄漏的都清掉」。
- 让它把出图脚本改成关服务时杀整棵进程树。

**Q：跨界转场的地方有一下跳。**
可能改过那段的代码画面、后期或字体。让 AI 做「关键帧逐像素一致」检查。
- 接缝本来就软的，用 6–12 帧交叉淡化。

**Q：水印 / 小字在手机上糊。**
字重太粗。水印用中等字重（500）加一点字距。

## 视频模型

**Q：本地视频模型跑到一半崩了，提示虚拟内存不足。**
把虚拟内存设成初始 65536 MB、最大 98304 MB（见 `01_电脑和网络.md`），关掉不用的程序，重启服务。

**Q：本地服务一启动就弹 DLL 错误框。**
有的自定义节点缺依赖（比如 TensorRT）。启动参数里禁用所有自定义节点，只放行必需的，例如视频输出节点。

**Q：生成的镜头不满意。**
- 先看提示词有没有按时间写清楚「先…… 然后…… 最后……」，主体够不够单一、强烈。
- 换种子重抽。
- 升级 2K（API）。

**Q：API 报 401 / 密钥无效。**
- 国内站的 Key 要用国内接口地址 `api.minimaxi.com`。
- 火山引擎的语音接口要用豆包语音控制台的 API Key，不是访问控制的 AK/SK。

**Q：API 连接超时。**
国内服务不要走代理；海外服务要走代理。让 AI 的脚本加自动重试。

## 声音

**Q：TTS 读错了一个字（多音字）。**
- 让 AI 把那个字换成同音字或加拼音标注，重新合成那一句。
- 可以让它用语音识别检查全部旁白。

**Q：成片在手机上声音太小。**
全片响度推到 −12 LUFS。只换音轨，不用重渲。

**Q：高潮不够炸。**
告诉 AI 感受，比如「高潮感觉没到位」。它可以：
- 加长高潮；
- 让最响的一刻落在顶点；
- 加更猛的写实镜头；
- 在顶点之后放一秒完全静音做反差。

## 交付

**Q：飞书发不出去 / 文件太大。**
飞书机器人单个文件上限 30 MB，用 720p 预览版（≤ 28 MB）。正式的上传版在电脑上直接传抖音。

**Q：2-pass 编码报「can't open stats file」。**
两个编码并行时，pass log 文件路径用了没定义的变量。让 AI 分开跑，或者把路径写死。
