# 05 跟 AI 沟通（最重要的一章）

片子拍得好不好，一半取决于你怎么说话。
**核心原则：你说「要什么」和「哪里感觉不对」，它负责「怎么做」。** 用看片的语言，不用技术的语言。

下面引号里的话，都是拍《足够震撼》《溢出》时制片人的原话，后面是 AI 实际做了什么。

---

## 1. 开工：第一句话怎么说

把这几样说清楚就够了：

| 要说的 | 例子 |
|---|---|
| 拍什么 | 「一部 AI 自己拍自己的续集」 |
| 多长、发哪 | 「3 分钟左右，横屏，发抖音」 |
| 参考和风格 | 「延续上一部的风格」「要震撼」 |
| 怎么干 | 「用多 agent 做」 |
| 怎么汇报 | 「每 10 分钟飞书 brief 任务情况和估算剩余时间」 |
| 先看什么 | 「先写个完整的剧本给我看」 |

**可以直接复制的开场（按需修改）：**
```
我想拍一部 3 分钟左右的横屏短片，发抖音，主题是「……」。
风格参考：……。
按 CLAUDE.md 的流程带我做。先检查环境，然后写一个完整的剧本给我看，开头给我 3 个版本选。
开工后用多 agent 做，每 10 分钟飞书 brief 任务情况和估算剩余时间。
```

## 2. 剧本阶段：先把「说什么」定死

剧本改一句只要几秒，片子做完再改要重做一大段。**所有对台词的意见都在这个阶段提。**

- **「开头要说出自己是 opus5.5」** → 加了自我介绍。
- **「我是 Opus 5.5 就行 简洁」** → 砍成最短版本。
- **「每一帧都不是拍的这个不够意外，一看就看出来了」** → 换钩子。好钩子要让观众意外。
- **「没有一帧是 AI 生成的也有问题，你不就是 AI 么」** → 换掉。好钩子还必须字面属实，旁白是 AI 在说。
- **不知道选哪个：** 说「给我 3 个版本」，挑一个，再说「第 2 个，但是……」。

## 3. 看片阶段：意见 = 位置 + 感受 + （可选）方向

| 原话 | AI 做了什么 |
|---|---|
| 「响度高一点 -12 吧」 | 全片响度从 −14 推到 −12 LUFS，只换音轨，不重渲画面 |
| 「开头进入主题的节奏再快一点，比如真实后面等的太久了」 | 查到那句旁白后面有 15.7 秒没有旁白，剪掉其中 12 秒，第一个写实镜头从 0:54 提前到 0:42 |
| 「最后溢出那个位置，让高潮再多来几秒，再切溢出，感觉没到位」 | 高潮加长 2 小节（4 秒），换了一条逐渐推高的烟花，音乐的最高点对准白屏那一帧 |
| 「溢出那个位置看看怎么做能更好一点，比如加点 glitch，然后接类似心跳的滴滴声」 | 字出现时 8 帧故障效果，之后每秒一次心跳：嘀嘀双响 + 边框闪 + 心电图线 |
| 「右上角爽哥说字体有点粗，都糊在一起了」 | 水印字重从 800 改到 500，加字距和淡阴影，压缩后也清楚 |

这几句都好用，因为：
- **说了位置：**「开头」「真实后面」「溢出那个位置」「右上角」。
- **说了感受：**「太久了」「没到位」「糊在一起了」。
- **有时给个方向：**「加点 glitch」「类似心跳的滴滴声」「-12」。
- **不用说技术细节：** 像「把 cues 里的 of_white 挪到 170」这种话，它自己会翻译。

**看不出问题在哪，就只说感受：**「这段有点闷」「这里太乱了」。它会给你几个改法选。

## 4. 进度：随时问，别干等

- **「还要多久」**：它会给具体时间点和剩下几步，例如「约 15:45，还有：渲染最后一段 6 分钟 → 合成 → 压缩 → 发飞书」。
- **「现在什么情况了，需要我做什么」**：它会列出已完成、进行中，以及需要你拍板的事。
- **飞书简报：** 开工时说一次「每 10 分钟飞书 brief」，之后在手机上看就行。
- **看中间结果：** 要缩略图、静帧或十几秒预览，比如「先发我开头 14 秒的预览」。不要让它为了一个小改动渲染整片。

## 5. 花钱：让它查、让它报价、你拍板

- **「你去搜搜用什么工具效果更好，我可以充值」** → 它上网查了 2026 年 9 月的视频模型盲测榜和各家价格，推荐了性价比最高的方案，并给出每条多少钱。
- **它会先报价：** 例如「9 条 × 6 秒 × ¥0.8 = 约 ¥43」。你回「升级」或「出 2K 烟花吧」才算同意。
- **先出一条再批量：**《溢出》升级 2K 时，先试了一条闪电，结果本地版反而更猛。所以后面是逐条对比，挑好的用，不是全换。
- **付费操作被拦下：** 这是正常的安全机制。按它说的用 `/permissions` 放行，或者自己用 `!` 运行它给的命令。

## 6. 让它查证：屏幕上的每个字都要是真的

- **随时问**「这个数字对吗？去查一下」。
- **真实案例：** 剧本里写了「上一部的纪录，十的六十四次方」。AI 回去翻上一部的代码，发现上一部其实一路算到了 10³⁰⁸，于是主动改了旁白、重新配音、重做高潮。
- **片尾署名、简介、封面文案也一样：**
  - 烟花是用 API 生成的，片尾就不能写「本地显卡生成」，要写「本地显卡 + 官方 API 生成」。
  - 这类细节它会自己改，你也可以提醒它。

## 7. 让它研究、给点子

- 「你搜搜 x 看还有什么有可能做出这种非常让人满意的视频的主题」
- 「帮我搜搜好用的 lora 之类的」
- 「看看怎么做能更好一点」

它会查资料、做小样、给你几个方向，你挑。

## 8. 出问题的时候

- **出错了：** 截图发给它，它能看图，说「有个错误，截屏看看」。
- **它好像在原地打转：** 按 `Esc` 打断，说「停一下，先告诉我现在卡在哪、试了什么」。
- **电脑卡了、内存满了：** 告诉它，它会查是什么进程占的。有一次是 124 个没关的预览进程占了 14 GB。
- **要你手动做的事**（重启某个服务、设置虚拟内存）：它会给你一步步的做法，做完回它一句「好了」。

## 9. 交付：一句话就行

- 「渲染完压抖音上传版」
- 「做个抖音封面，横竖都要」（再补一句「4:3」「加上我的抖音头像」）
- 「简介来一个」：标题 3 选 1 + 正文 + 话题
- 「发我飞书」

## 10. 别这样

- **别一次甩十条互相打架的意见：** 一次两三条，看完新版再说。
- **别让它编数据：** 屏幕上、简介里的数字都要有出处。
- **别在它干活时关窗口或让电脑睡眠：** 活会停。
- **别把所有安全确认都关掉：** 省一分钟，可能换来误删文件或误扣钱。
