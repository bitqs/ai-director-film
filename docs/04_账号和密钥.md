# 04 账号和密钥

所有密钥都放在项目根目录的 **`.env`** 文件里（仓库里有 `.env.example`，复制一份改名为 `.env` 再填）。
`.env` 已经写进 `.gitignore`，不会被上传。

```
VOLC_SPEECH_API_KEY=你的豆包语音 API Key
MINIMAX_API_KEY=你的 MiniMax 开放平台 API Key
ELEVENLABS_API_KEY=你的 ElevenLabs API Key
HTTPS_PROXY=                     # 访问海外服务要代理的话填，例如 http://127.0.0.1:7890
FEISHU_USER_OPEN_ID=             # 飞书简报发给谁（可选）
```

> **最省事的做法：** 你直接把 Key 发给 AI，说「帮我存进 .env」，它会存好并且不在回复里显示。
> 但聊天记录里还是留下了 Key，**项目做完后建议去后台把它作废、重新生成一个**。

## 1. 旁白配音：火山引擎「豆包语音」（必须）

两部片子的旁白都是豆包语音合成模型 2.0，音色「高冷沉稳」。它支持**逐字时间戳**：每个字在第几秒念出来，画面的字幕和卡点全靠它。

1. 打开火山引擎官网，注册并完成实名认证。
2. 在控制台找到「豆包语音」，开通语音合成大模型（2.0）服务。是否有免费额度以官方为准，按量付费的话一部片子也就几毛钱。
3. 在豆包语音的控制台里创建 **API Key**，填进 `.env` 的 `VOLC_SPEECH_API_KEY`。

**常见坑：** 火山引擎有好几种「密钥」。
- 语音接口要的是**豆包语音控制台里的 API Key**，放在请求头 `X-Api-Key` 里。
- 「访问控制」里的 AK/SK（Access Key ID / Secret）和别的 Key ID/Secret 不能直接用在语音接口上，会报 401。
- 分不清的话，把你拿到的都交给 AI，它可以用 AK/SK 调火山的管理接口把正确的语音 Key 查出来。

**免费替代：** 微软的 edge-tts 不要钱，但声音差一些，也没有逐字时间戳，要靠估算。

## 2. 写实镜头：MiniMax 开放平台（档位 ②）

1. 打开 MiniMax 开放平台国内站（platform.minimax.cn），注册并实名。
2. 充值（人民币）。两部片子的用量参考：H3 2K 视频 ¥0.8/秒，一条 6 秒约 ¥5，一部片 ¥50–100 足够。
3. 创建 API Key，填进 `.env` 的 `MINIMAX_API_KEY`。国内站的接口地址是 `api.minimaxi.com`，直连，不走代理。

**控制花费：** AI 每次要调付费接口都会先告诉你「几条 × 几秒 × 单价 = 多少钱」，等你同意。
先让它出**一条**试试效果，满意再批量。

## 3. AI 配乐和音效：ElevenLabs（可选）

- **用途：** 交响乐这类「真乐器」的配乐，以及音效（碎玻璃、烟花、风暴……）。
- **可以不用：** 全部用代码合成也行，《足够震撼》的配乐就是纯代码合成的。
1. 注册 ElevenLabs，订阅一个付费档（商用授权按它的条款）。
2. 在个人设置里生成 API Key，填进 `ELEVENLABS_API_KEY`。
3. 它是海外服务，访问需要你的网络支持，见 `01_电脑和网络.md`。

## 4. 飞书（可选，强烈推荐）

**用途：**
- 每 10 分钟往你手机发一条进度简报：在做什么、还要多久；
- 直接把成片预览、封面发到手机。

1. 安装 lark-cli：`npm install -g @larksuite/cli`。
2. 在飞书开放平台创建一个企业自建应用（机器人），开通「以应用身份发消息」的权限，发布版本。
3. 按 lark-cli 的说明配置应用并登录。
4. 让 AI 帮你查到你自己的 open_id，填进 `FEISHU_USER_OPEN_ID`。

- **单个文件上限：** 飞书机器人发的单个文件不能超过 30 MB。所以 AI 会另外压一个 720p 的手机预览版（≤ 28 MB）发给你，正式的上传版留在电脑上。

## 5. GitHub（可选）

想把自己的工程存到网上或分享出去，就注册 GitHub。第一次推送时，Git 会弹出浏览器让你登录。

## 安全清单

- [ ] `.env` 从不发给别人，从不上传
- [ ] 各平台都设置消费提醒或额度上限
- [ ] 项目结束后，把在聊天里贴过的 Key 作废重建
- [ ] 火山引擎的「访问控制」主账号 AK/SK 权限很大，用完就禁用；只给语音用的话，建一个只有语音权限的子账号
