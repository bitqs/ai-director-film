# 02 安装软件

下面以 **Windows** 为例，用系统自带的 `winget` 安装。在开始菜单搜「PowerShell」打开，一条一条复制运行。
**每装完一个，运行后面的「检查」命令**，能看到版本号就说明装好了。
全部装完后**关掉 PowerShell 重新打开一次**，新装的命令才会生效。

> 其实装好 Git 和 Claude Code 之后，剩下的都可以让 AI 带你装：它会先检查缺什么，再给你命令。

## 1. Git（必须）

Claude Code 在 Windows 上需要 Git 自带的 Git Bash。拉取渲染引擎、管理版本也要用。
```powershell
winget install --id Git.Git -e
```
检查：`git --version`

## 2. Node.js（必须）

Claude Code 和渲染工程都依赖它。
```powershell
winget install --id OpenJS.NodeJS.LTS -e
```
检查：`node -v`（18 以上即可，两部片子用的是 24）

## 3. Bun（必须）

渲染工程用它启动开发服务器、跑渲染脚本，比 npm 快。
```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```
检查：`bun --version`

## 4. Python（必须）

配音、排时间轴、混音、调视频模型接口的脚本都是 Python。
```powershell
winget install --id Python.Python.3.12 -e
```
检查：`python --version`

然后建一个专用环境，装音频处理要用的库（在你的项目目录里运行）：
```powershell
python -m venv .venv
.venv\Scripts\pip install numpy scipy soundfile pyloudnorm pillow
```
- 装得慢：可以让 AI 帮你换国内镜像源。
- Windows 控制台显示中文乱码：运行 Python 前先设 `$env:PYTHONIOENCODING="utf-8"`，AI 一般会自己加。

## 5. ffmpeg（必须）

所有音视频的合成、剪切、编码、测响度都靠它。
```powershell
winget install --id Gyan.FFmpeg -e
```
检查：`ffmpeg -version`

## 6. Google Chrome（必须）

渲染时用「无头 Chrome」一帧一帧截取画面。
```powershell
winget install --id Google.Chrome -e
```

## 7. 可选

| 软件 | 用途 | 安装 |
|---|---|---|
| VS Code | 方便看 AI 写的文件、剧本 | `winget install --id Microsoft.VisualStudioCode -e` |
| lark-cli | 把成片和进度发到飞书 | `npm install -g @larksuite/cli`，配置见 `04_账号和密钥.md` |
| Blender | 给视频模型做镜头运动参考（高级） | `winget install --id BlenderFoundation.Blender -e` |

## 8. 档位 ③：本地跑视频模型（高级，可以先跳过）

- **NVIDIA 驱动：** 装最新的 Studio 或 Game Ready 驱动。
- **ComfyUI：** 下载官方便携版，解压就能用。
- **MiniMax H3 开源权重：** 从 MiniMax 官方开源发布页获取，按显存选压缩版。16 GB 显存要用 int8 压缩权重 + 8 步加速 LoRA，分辨率 1344×768。
- **虚拟内存：** 按 `01_电脑和网络.md` 调大，否则会崩。
- **启动方式：** 视频模型的服务**你自己**双击批处理启动，开在自己的窗口里，不要让 AI 在后台启动。内存紧张时后台进程会被系统杀掉。

这一步 AI 可以一步步带你做：对它说「我要在本地跑 MiniMax H3，按 docs/08_视频模型.md 带我装」。

## macOS 用户

把 `winget install` 换成 Homebrew：
```bash
brew install git node python@3.12 ffmpeg
brew install --cask google-chrome
curl -fsSL https://bun.sh/install | bash
```
档位 ③（本地视频模型）需要 NVIDIA 显卡，Mac 上不适用，用档位 ②（API）代替。

## 全部检查一遍

```powershell
git --version; node -v; bun --version; python --version; ffmpeg -version
```
五行都有版本号，就可以进入下一章了。
