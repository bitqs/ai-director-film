# 10 导出与发布

## 渲染

- **规格：** 1080p、60 帧、自适应运动模糊（每帧 12–324 个子帧，快门 0.2）。3 分钟的片子在 RTX 4080 SUPER 上约 18 分钟。
- **先出无声画面，再合成声音：** 改混音、改响度只换音轨，不用重渲。
- **剪辑用「旧时间轴 + 剪点」：** 例如删掉中间 12 秒。工程时间轴不改，成片 = 旧 [0, 30) + 旧 [42, 结尾)。场景和转场接缝都不受影响，只重渲变了的段，再无损拼接。
- **改了一处，只渲那一段：** 同一编码参数的分段可以用 ffmpeg concat 直接拼（`-c copy`）。

## 编码：三个版本

| 版本 | 参数 | 用途 |
|---|---|---|
| 母版 | 渲染输出 + AAC 320k | 存档、以后再剪 |
| **抖音上传版** | 1080p60，x264 2-pass 27 Mbps（maxrate 40M），AAC 320k | 上传抖音 |
| 手机预览版 | 720p30，x264 2-pass 1 Mbps，AAC 96k，≤ 28 MB | 发飞书，手机上看 |

说一句「渲染完压抖音上传版」，AI 就会全部做好。

## 封面

- **尺寸：** 横版 4:3（2160×1620）+ 竖版 3:4（1620×2160）。横版是视频封面，竖版给主页网格用。
- **内容：**
  - 片名要大；
  - 副标题用最有钩子的一句旁白；
  - 头像 + 频道名 + 片长；
  - 背景可以用成片里最炸的一帧：用 2 倍分辨率单独渲染，裁掉画面里的水印。
- **做法：** `examples/封面模板/cover.html` 是网页模板，AI 用无头 Chrome 截图出图。改字、换背景都只要一句话。
- **细节：** 小字放在花背景上一定要垫深色底；频道名别用太粗的字重。

## 水印

右上角「• 频道名」，**每一帧都有**，证明是你的原创。
- **字重：** 用中等字重（500）+ 一点字距 + 淡阴影。粗体在抖音压缩后会糊成一团。
- **会改变每一帧：** 所以要在最终渲染前定好。改一次就得全片重渲。

## 发布文案

说「简介来一个」，AI 会给：
- 标题三选一；
- 正文；
- 话题标签；
- 发布建议：合集、置顶评论。

**每一句都要字面属实。** 数字要能在工程文件里找到出处。

## 发布前检查

- [ ] 画面帧数 = 时长 × 60，音视频时长一致
- [ ] 响度 −12 LUFS，峰值 ≤ −1 dB
- [ ] 抽帧拼图看一遍：剪点、转场、高潮、片尾、最后一帧
- [ ] 片尾署名和实际一致：谁做了什么；用了 API 就写 API
- [ ] 抖音上勾选「**内容由 AI 生成**」（有 AI 生成的画面，配音也是合成的）
- [ ] 标题、简介每句属实

## 合规和版权

- **AI 标注：** 按平台规定勾选。片尾署名写清每部分由谁、用什么做的。
- **商用授权：** 发抖音接广告、接商单、卖课之前，逐个确认各服务的条款，这些条款各家不一样，也会变：
  - AI 配乐（ElevenLabs）；
  - TTS 配音（豆包语音）；
  - 视频模型（MiniMax H3 的 API 输出和开源权重）。
- **引擎和字体：**
  - 渲染引擎基于 pdoom-video（MIT），二次分发代码时保留它的 LICENSE。
  - 用到的字体都是 OFL 开源字体，可以商用。
- **别碰真人：** 不要生成真实存在的人、别人的品牌、别人的作品。
