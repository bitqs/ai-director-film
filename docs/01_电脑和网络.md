# 01 电脑和网络

## 电脑要求

| | 档位 ① 纯代码片 | 档位 ② 加写实镜头（API） | 档位 ③ 本地显卡出片 |
|---|---|---|---|
| 系统 | Windows 10/11 或 macOS | 同左 | Windows 10/11（NVIDIA 显卡） |
| 内存 | 16 GB 起，32 GB 更稳 | 同左 | **32 GB 是下限**，另需把虚拟内存设到 64–96 GB |
| 显卡 | 普通独显或核显都能渲染，只是慢 | 同左 | **NVIDIA 16 GB 显存起**（两部片子用的是 RTX 4080 SUPER） |
| 硬盘 | 空闲 50 GB | 空闲 80 GB | 空闲 200 GB（模型权重就很大） |

- **渲染速度：** 3 分钟 1080p60 的片子，全片渲染在 RTX 4080 SUPER 上约 18 分钟。显卡越弱越慢，但都能渲出来。
- **硬盘占用：** 每出一版成片约 2–3 GB（无损母版 + 各种编码版本）。每条写实镜头转成逐帧图片后约 30–70 MB。

## 系统设置（Windows）

- **长任务别让电脑睡着：**「设置 → 系统 → 电源」，接通电源时「从不」睡眠。渲染和出片动辄半小时。
- **档位 ③ 要把虚拟内存调大：**「设置 → 系统 → 关于 → 高级系统设置 → 性能 → 设置 → 高级 → 虚拟内存 → 更改」。
  - 取消「自动管理」，选 C 盘或空间大的盘。
  - 自定义大小：初始 65536 MB，最大 98304 MB。
  - 点「设置」再点「确定」。本地视频模型大约要 35 GB 提交内存，不调大会在出片中途崩溃（系统提示「虚拟内存不足」）。
- **路径尽量用英文：** 项目放在类似 `D:\Projects\` 的位置。中文路径大多数工具能处理，但偶尔会出怪问题。

## 网络

整条流程会连这些服务：

| 服务 | 在哪 | 用来干什么 |
|---|---|---|
| Claude（Claude Code） | 海外 | AI 导演本身 |
| 火山引擎（豆包语音） | 国内 | 旁白配音 |
| MiniMax 开放平台（国内站） | 国内 | 写实镜头 |
| ElevenLabs | 海外 | AI 配乐、音效（可选） |
| GitHub、npm、Google Fonts | 海外 | 下载工具、引擎、字体 |
| 飞书 | 国内 | 把成片和进度发到手机（可选） |

- **Claude 的地区限制：** 请先确认你所在的国家和地区在 Anthropic 的服务支持范围内，并遵守它的服务条款。
- **海外服务要能访问：** 如果你的网络访问海外服务需要走代理，把代理地址写进 `.env` 的 `HTTPS_PROXY`，AI 调这些服务时会用上。国内服务（火山引擎、MiniMax 国内站）直连就行，不要走代理。
- **网络不稳：** 装软件、下载模型、调接口时都可能超时。AI 写的脚本应该能自动重试。碰到超时，跟它说「网络超时了，加重试再来一次」。
