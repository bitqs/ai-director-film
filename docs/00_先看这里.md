# 00 先看这里

## 这是怎么回事

你用大白话告诉 AI 想拍什么，AI 替你干掉所有技术活：
- 写剧本、写旁白；
- 用代码一帧一帧「画」出动画（不是剪辑软件，是程序渲染）；
- 调配音、音乐、视频模型的接口；
- 把几十个素材按鼓点对齐，渲染、合成、压成抖音能用的文件。

你要做的只有四件事：
1. 给需求
2. 看片
3. 提意见
4. 决定要不要花钱

## 最后你会得到

- 一部约 3 分钟、1080p 60 帧的横屏短片，带旁白、配乐、音效，响度适合手机外放。
- 抖音上传版 + 手机预览版 + 横竖两张封面 + 发布文案。
- 整个工程文件夹：以后改一句台词、换一个镜头，只需要跟 AI 说一句。

## 要多久

| 阶段 | 第一次 | 熟练后 |
|---|---|---|
| 装软件、注册账号 | 1–2 小时 | 0 |
| 剧本 + 配音 + 时间轴 | 30–60 分钟 | 20 分钟 |
| 画面制作（AI 干活，你偶尔看图） | 2–4 小时 | 2–3 小时 |
| 写实镜头（档位 ②③） | 本地 2 小时 / API 10 分钟 | 同左 |
| 审片、改片、导出 | 1–2 小时 | 1 小时 |

**真实参考：** 《溢出》从开工到交付第三版约 5 个半小时，中间改了三版。

## 要花多少钱

| 项目 | 必须吗 | 大概多少 |
|---|---|---|
| Claude 订阅（Claude Code 用） | 必须 | 按官方订阅价；做片子这种大活建议用高一档的套餐 |
| 旁白配音（豆包语音） | 必须（或用免费的 edge-tts 凑合） | 一部片几毛钱 |
| 写实镜头 API（MiniMax） | 档位 ② | 2K ¥0.8/秒，一部片 ¥50–100 |
| AI 配乐（ElevenLabs） | 可选（也可以全用代码合成） | 订阅 |
| 显卡（本地出片） | 档位 ③ | 你已有的电脑 |

## 读文档的顺序

1. `01_电脑和网络.md` → `02_安装软件.md` → `03_安装Claude_Code.md` → `04_账号和密钥.md`：装好就行，一次性的。
2. `05_跟AI沟通.md`：**一定要读**。拍得好不好，主要看你怎么提需求和意见。
3. 开拍。遇到问题查 `12_常见问题.md`。
4. 其他章节是「想知道 AI 在干什么」时再看。

## 心态

- **你是制片人，不是程序员。** 看不懂代码完全没关系，看得懂画面就行。
- **AI 会犯错，你负责把关。**
  - 它写的每个数字、每个事实，你可以随时问：「这个对吗？去查一下。」
  - 《溢出》的剧本里就有一句写错了，是它自己回去翻代码查出来改掉的。
- **第一版不会完美。** 看完提意见，改到第三版通常就很好了。
