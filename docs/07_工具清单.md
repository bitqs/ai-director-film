# 07 工具清单：到底调用了什么

## AI 本身

| 工具 | 在这里干什么 |
|---|---|
| **Claude Code**（模型 Claude Opus 5.5） | 导演 + 所有分身：写剧本、写代码、写提示词、看图审片、调度 |
| Claude Code 的内置能力 | 读写文件、运行命令、上网搜索和抓网页、**开分身（Agent）并在分身间转达消息**、后台任务、看图片 |

## 画面

| 工具 | 干什么 | 备注 |
|---|---|---|
| **pdoom-video 引擎**（[mexicat/pdoom-video](https://github.com/mexicat/pdoom-video)，MIT） | 起点：TypeScript + three.js 逐帧渲染框架，自带运动模糊、胶片后期、HUD | AI 在它基础上加中文字体、逐字字幕、同步点、视频贴片 |
| three.js / WebGL / Canvas 2D | 画面本身：网格、粒子、文字、光效、玻璃碎片 | |
| Vite + Bun | 本地开发服务器、跑渲染脚本 | |
| 无头 Chrome（playwright-core） | 一帧一帧截取画面导出 | |
| 字体：Noto Sans SC、Archivo、IBM Plex Mono | 中文、数字、等宽 | 都是开源字体（OFL），可商用 |

## 写实镜头

| 工具 | 干什么 | 备注 |
|---|---|---|
| **MiniMax H3**（官方 API） | 文生视频、首尾帧转场，原生 2K，带环境声 | 2026 年 9 月盲测榜：纯画质文生视频第 3、带声图生视频第 2 |
| MiniMax H3（开源权重 + ComfyUI，本地） | 同上，在自己显卡上跑 | 16 GB 显存需压缩权重 + 8 步加速，1344×768 |
| Blender | 做镜头运动参考视频（可选，高级） | |

**可以替换成：** 阿里云百炼的 Wan 3.0（纯画质榜第 1，1080P ¥1.2/秒）；Gemini Omni Flash（原生 720p，需海外付费）；Seedance 2.0（火山方舟）。
换模型只需要改出片脚本的接口部分，其他流程不变。

## 声音

| 工具 | 干什么 | 备注 |
|---|---|---|
| **豆包语音合成 2.0**（火山引擎） | 旁白，带逐字时间戳 | 两部片子用的音色：「高冷沉稳」 |

## 合成、编码、交付

| 工具 | 干什么 |
|---|---|
| **ffmpeg** | 合成音画、剪辑拼接、编码（x264 2-pass）、测响度（ebur128）、抽帧拼图 |
| lark-cli（飞书） | 机器人私信：进度简报、预览视频、封面 |
| Git / GitHub | 版本管理、分享 |

## 仓库里的参考脚本（`scripts/`）

| 脚本 | 干什么 |
|---|---|
| `tts_豆包示例.py` | 豆包语音逐句合成，带逐字时间戳（依赖工程里的 `script.py`，照着改） |
| `plan_示例.py` / `cues_示例.py` | 按 120 BPM 排时间轴、生成同步点 |
| `h3_api.py` | MiniMax 官方 API 出片：提交、轮询、下载，网络断了自动重试 |
| `h3_shot2.py` / `h3_fl2v.py` | 本地 ComfyUI 跑 H3：文生、参考生、首尾帧 |
| `run_queue.py` | 本地出片队列：一次一条，服务挂了就等 |
| `clips.py` | 写实镜头转逐帧图片，给渲染引擎用 |
| `brief_loop.py` | 每 10 分钟往飞书发进度简报 |

这些脚本是从真实工程里摘出来的，**路径和参数要按你的工程改**。直接交给 AI，让它照着改最省事。
