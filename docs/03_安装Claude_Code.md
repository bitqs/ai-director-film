# 03 安装 Claude Code

Claude Code 是 Anthropic 出的 AI 编程助手，在命令行里运行。它能读写文件、运行命令、上网查资料、开多个分身并行干活。在这套方法里，它就是**导演**。

## 账号

- 需要一个 Claude 账号，订阅 Pro 或 Max；也可以用 Anthropic Console 的 API 按量付费。
  - 拍片是很重的活：写几千行代码、看几百张图、开多个分身。建议用高一档的订阅，否则容易碰到用量上限。
- 先确认你所在的国家和地区在 Anthropic 的服务支持范围内，并遵守它的服务条款。

## 安装

官方原生安装（Windows PowerShell）：
```powershell
irm https://claude.ai/install.ps1 | iex
```
或者用 npm 安装（已经装了 Node.js 的话）：
```powershell
npm install -g @anthropic-ai/claude-code
```
检查：`claude --version`

## 第一次启动

1. 在 PowerShell 里进入这个仓库的目录（下载 / 克隆下来的文件夹）：
   ```powershell
   cd D:\Projects\ai-director-film
   claude
   ```
2. 按提示登录（会打开浏览器）。
3. 登录后就可以直接打中文跟它说话了。它在这个目录里启动，会自动读 `CLAUDE.md`，也就是它的导演手册。

## 必须会的几个操作

| 操作 | 怎么做 | 什么时候用 |
|---|---|---|
| 说话 | 直接打字回车 | 下需求、提意见、问进度 |
| 打断它 | 按 `Esc` | 发现它跑偏了 |
| 自己运行一条命令 | 在输入框里以 `!` 开头，例如 `! python --version` | 需要你亲自登录、亲自付费、看结果时 |
| 权限设置 | 输入 `/permissions` | 放行某类操作，例如调用付费接口 |
| 换模型 | 输入 `/model` | 用最强的模型拍片 |
| 查看帮助 | 输入 `/help` | 忘了命令时 |
| 接着上次聊 | 启动时 `claude --resume`，或输入 `/resume` | 关了窗口第二天继续 |

## 权限：它什么时候会停下来问你

Claude Code 会在做有风险的事之前停下来：
- 删文件、改系统设置；
- 调用会扣钱的接口；
- 把东西发到网上。

- **自动模式：** 常规操作不打扰你，高风险操作会被拦下。碰到被拦的付费操作，AI 会告诉你金额和原因。你同意的话，用 `/permissions` 放行，或者照它给的命令自己用 `!` 运行一次。
- **别关掉所有确认。** 被拦一下可能多等一分钟，却能防止它误删文件、误花钱。

## 多个分身（多 agent）

跟它说「用多 agent 做」或者「可以根据需要开 agent」，它就会按段落开几个分身同时干活：一个做开场，一个做高潮，一个管声音……它自己当导演，负责派活、对时间、审片。
- 分身越多越快，但用量也越大。一部 3 分钟的片子，开 5–7 个比较合适。
- 分身之间不直接对话，都由导演转达。所以你只需要跟导演说话。

## 在手机上看进度

- **飞书简报：** 对它说「每 10 分钟飞书 brief 任务情况和估算剩余时间」，它会用 `scripts/brief_loop.py` 定时发简报。需要先配好 lark-cli，见 `04_账号和密钥.md`。
- **成片和预览：** 也可以让它直接发到飞书，手机上就能看。

## 小提醒

- **电脑不要关、不要睡眠：** 窗口关了，它的活就停了。它在后台跑的任务，比如渲染，跟随这个窗口的生命周期。
- **上下文太长时：** 它会自动压缩，一般不用管。重要的决定它会记在项目文件里（例如 `PRODUCTION.md`、`STATUS.json`）。
