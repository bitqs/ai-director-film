## Claude 的 token 成本（最大的一笔）

从会话日志逐条统计，包含导演和所有分身，按 Claude Opus 5.5 的 API 标价折算（输入 $4、输出 $20、缓存读取 $0.20，都是每百万 token）：

| | 《足够震撼》 | 《溢出》 |
|---|---|---|
| 请求次数 | 1,517 | 1,825 |
| 总 token | 约 4.9 亿 | 约 7.9 亿 |
| 其中缓存读取 | 97% | 98% |
| 按 API 价格 | 约 $168 | 约 $253 |

- **这是按 API 价格算的参考值：** 用 Claude 订阅的话，这部分包含在订阅里。
- **还有一次性的研发：** 原型试验、搭本地视频模型工作流，约 $284。照这个教程做就不会再有这笔。
- **为什么贵：** 每一步都要把整段上下文重读一遍，而分身的上下文动辄 40–50 万 token。
- **怎么省：** 已写进 `CLAUDE.md` 的「省 token」一节：
  - 一部片子一个会话；
  - 分身 4–5 个；
  - 每个分身上下文控制在 20 万以内；
  - 不唤醒大的老分身做小改动；
  - 意见合并着改；
  - 机械活用 Sonnet。
  同样一部《溢出》估计能降到 $100–120。

## 翻车记录（照样会发生，别慌）

- **11:01，本地视频模型崩溃：** Windows 虚拟内存不足。清掉泄漏的进程、调大虚拟内存、手动重启服务，丢了一条镜头，重跑就好。
- **124 个预览进程占了 14 GB 内存：** 分身们出缩略图时开的服务没关干净，改成杀整棵进程树后解决。
- **剧本里写错一个数字：** AI 自己查出来改了，重新配音、重做高潮。
- **AI 安全检查偶尔超时：** 命令暂时跑不了，等几分钟再说一句话就恢复了。
