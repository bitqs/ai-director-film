# 09 声音

声音是「震撼」的一半。整部片的声音分四层：

| 层 | 来源 | 例子 |
|---|---|---|
| 旁白 | 豆包语音 2.0（TTS） | 「我是 Opus 5.5。」 |
| 配乐 | 代码合成的电子乐 + AI 交响乐（可选） | 四踩底鼓、合成器、弦乐铜管 |
| 音效 | 代码合成 + AI 音效（可选） | 盖章、指针撞击、玻璃碎裂、心跳嘀嘀 |
| 环境声 | 写实镜头自带 | 焊枪嘶鸣、雷声、浪声、火箭轰鸣 |

## 旁白

- **逐句合成，要逐字时间戳：** 豆包语音开 `enable_subtitle`。每个字在第几秒念出，字幕和卡点都靠它。
- **换声音：** 让 AI 用同一句话合成几个音色给你挑。两部片子都用「高冷沉稳」：冷静、克制，像电影预告片旁白。
- **读错字：** 可以让 AI 用语音识别（ElevenLabs Speech-to-Text）自己检查一遍。

## 配乐

- **纯代码合成：**《足够震撼》的配乐全是 Python 代码合成的，和鼓点、画面完全同步，一分钱不花。
- **AI 交响乐：**《溢出》后半段用 ElevenLabs Music 生成交响乐，按段落时长生成后对齐到节拍网格。
- **节拍网格是全片的骨架：** 120 BPM，1 小节 = 2 秒。旁白、画面事件、音乐段落都落在网格上。

## 音效：每个画面事件都要有声音

- 让画面分身报出每个事件的**精确时间**，例如「171.500 故障、172.0 心跳」，转给声音分身。
- **规矩：** 每个声音都要有画面，每个画面事件都要有声音。只有画面没有声音，观众会觉得「空」；只有声音没有画面，会觉得「乱」。
- **静音也是设计：**《溢出》白屏之后一整秒完全静音，再「嘀」一声出字，比一直响更有冲击力。

## 响度（按抖音来）

| 指标 | 数值 |
|---|---|
| 全片响度（integrated） | **−12 LUFS**（−14 在抖音偏小，这是爽哥的实测意见） |
| 真峰值 | WAV ≤ −1.5 dBTP，AAC 编码后 ≤ −1.0 dBTP |
| 人声 | 任何一句都比背景高 7 dB 以上 |
| 最响的一刻 | 落在高潮顶点，例如白屏那一下 |

- **推响度用母带限幅器，不要用会「抽吸」的响度归一化。**
- **堆层推不上去的时候：** 高潮层数堆多了，限幅器会把它压平。可以在最后两小节用短暂的软削波推一把，让最响点落在该落的那一帧。
- **只改声音时，只换音轨：** 画面不用重渲，几秒钟就好。

## 听的时候注意

AI 听不见声音，只能靠测量检查。所以它发你混音时会列出「请重点听」的几处。**一定要戴耳机听一遍**，重点听这些：
- 交响乐真不真；
- 有没有地方刺耳、糊、太吵；
- 人声清不清楚；
- 高潮够不够顶。
