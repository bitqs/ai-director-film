# 起手对话：每个阶段可以直接复制的话

在这个仓库目录里打开 Claude Code（`claude`），按阶段复制下面的话，把「……」换成你的内容。

## 0. 第一次用：检查环境

```
我是新手，第一次用。按 CLAUDE.md 帮我检查环境：缺什么软件，一个个教我装；然后帮我把 .env 配好。
```

## 1. 开工

```
我想拍一部 3 分钟左右的横屏短片，发抖音，主题是「……」。
风格参考：……（例如：像《足够震撼》那样纯代码画面 / 像《溢出》那样代码变成写实画面）。
按 CLAUDE.md 的流程带我做。先写一个完整的剧本给我看，开头给我 3 个版本选。
```

## 2. 改剧本

```
开头用第 2 个，但是再短一点。
这一句「……」不对，你查一下是不是真的。
整体太长了，压到 3 分钟以内。
```

## 3. 配音

```
先把旁白配出来发我听。声音要冷静、克制，像电影预告片旁白。给我两三个音色选。
```

## 4. 正式开拍

```
剧本定了，开工，用多 agent 做。
每 10 分钟飞书 brief 任务情况和估算剩余时间。
每个部分做好先发我缩略图，不用等整片。
```

## 5. 加写实镜头（档位 ②）

```
这一段要真实画面：……（描述画面）。用 MiniMax H3 的 API 出 2K，先出一条给我看，告诉我多少钱。
```

```
你去搜搜现在用什么视频模型效果最好、多少钱，我可以充值。
```

## 6. 看片提意见（位置 + 感受 + 方向）

```
开头进入主题的节奏再快一点，比如「……」后面等的太久了。
高潮再多来几秒再切，感觉没到位。
这里加点 glitch，然后接类似心跳的滴滴声。
响度高一点，-12 吧。
右上角的字有点粗，糊在一起了。
```

## 7. 问进度

```
还要多久？
现在什么情况了，需要我做什么？
先发我开头 14 秒带声音的预览。
```

## 8. 交付

```
渲染完压抖音上传版，发我飞书一个手机能看的预览版。
做个抖音封面，横竖都要，4:3 和 3:4，加上我的头像（头像在 ……）。
简介来一个：标题给我 3 个选，每句都要属实。
```

## 9. 做完以后

```
把这次的真实制作数据整理一下：花了多少钱、多少时间、改了几版，做一期幕后视频的脚本。
```
