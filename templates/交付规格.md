# 05 交付规格

## 渲染

- **规格：** 1080p60，逐帧确定性渲染（每一帧只依赖时间 t）。
  - 自适应运动模糊：每帧 12–324 个子帧，快门 0.2。
  - 一台 RTX 4080 SUPER 上，3 分钟的片子全片约 18 分钟。
- **先出无声画面：** 声音单独做，最后合成。改混音、改响度只需要换音轨，不用重渲。
- **剪辑用「旧时间轴 + 剪点」：** 工程里的时间轴不改，成片 = 旧 [0, 30) + 旧 [42, 结尾)。场景、同步点、生成镜头的接缝都不受影响，只需要重渲变了的那一段。
- **分段渲染再无损拼接：** 同一套编码参数渲染的几段，可以用 ffmpeg concat 直接拼（`-c copy`）。
- **渲染前必做：** 跨界关键帧检查。代码画面在转场起点那一帧必须和给视频模型的首帧逐像素一致，改过后期、调色或字体都会破坏接缝。

## 响度

- **全片 −12 LUFS（integrated）。** 爽哥说：−14 不够响。
- **真峰值：** WAV ≤ −1.5 dBTP，AAC 编码后 ≤ −1.0 dBTP。
- **用母带限幅器推响度，别用会「抽吸」的响度归一化。**
- **人声：** 任何一句都要高出背景 7 dB 以上。
- **高潮：** 全片最响的一刻要落在高潮的顶点（这里是白屏那一下）。只靠堆层会被限幅器压平；用一个短暂的软削波推一把。

## 编码

| 版本 | 参数 | 用途 |
|---|---|---|
| 母版 | 渲染器输出（x264 CRF 16）+ AAC 320k | 存档 |
| 抖音上传版 | 1080p60，x264 2-pass 27 Mbps（maxrate 40M），AAC 320k | 上传 |
| 飞书预览 | 720p30，x264 2-pass 1 Mbps，AAC 96k | 手机上看效果，飞书单文件 ≤ 30 MB |

- **2-pass 并行编码：** 注意 passlogfile 路径别用在子 shell 里才定义的变量，否则第二遍找不到统计文件。

## 封面

- **尺寸：** 横版 4:3（2160×1620）+ 竖版 3:4（1620×2160）。
- **内容：**
  - 背景是成片里真实的一帧：高潮时刻，用 2 倍分辨率渲染，裁掉画面里的水印。
  - 片名要大，副标题用旁白里最有钩子的一句（例如「上一部，我只算到 10³⁰⁸」）。
  - 头像 + 频道名 + 片长。
- **做法：** `examples/封面模板/cover.html` 是网页模板，无头 Chrome 截图出图。
- **小字标签：** 放在花背景上一定要垫深色底，不然看不清。

## 水印

- **位置：** 右上角「• 频道名」，每一帧都有。
- **字重：** 中等（500）+ 6% 字距 + 淡阴影。800 粗体在压缩后会糊成一团，「爽」这种笔画多的字最明显。

## 发布前检查

- [ ] 画面帧数 = 时长 × 60；音频、视频时长一致
- [ ] 响度 −12.0 LUFS，峰值 ≤ −1 dB
- [ ] 抽 15–20 帧拼图审一遍：剪点、跨界、高潮、片尾、最后一帧
- [ ] 片尾署名和实际一致（用了 API 就写 API）
- [ ] 勾选「内容由 AI 生成」
- [ ] 标题、简介每句都字面属实
