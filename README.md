# AI 导演拍片

**用 AI 当导演，拍一部 3 分钟的短片。** 不会写代码也能上手：你当制片人，提需求、看片、提意见；AI（Claude Code）当导演，写剧本、写代码、调工具、开多个分身并行干活，最后交出能直接发抖音的成片。

这个仓库是「爽哥说」两部片子的制作方法：
- **《足够震撼》：** 纯代码画面，AI 用代码「算」出每一帧。
- **《溢出》（续集）：** 代码画面 + 视频模型生成的写实镜头，靠首尾帧转场从代码「变成真的」。

照着做，你能拍出同一类的片子：代码动画 + 旁白 + 配乐，可选写实镜头。

---

## 先看你走哪条路

| 档位 | 能拍出什么 | 需要 | 额外花费 |
|---|---|---|---|
| **① 纯代码片** | 像《足够震撼》：全部画面由代码渲染 | 一台普通电脑 + Claude Code | 旁白配音几毛钱 |
| **② 加写实镜头（API）** | 像《溢出》：代码画面 + 视频模型的写实镜头 | 同上 + MiniMax 开放平台账号 | 2K 写实镜头约 ¥0.8/秒，一部片约 ¥50–100 |
| **③ 本地显卡出片** | 同 ②，写实镜头在自己显卡上跑 | NVIDIA 显卡 16 GB 显存 + 32 GB 内存 | 电费 |

**新手建议：** 先走 ①，跑通整条流程，再加 ②。③ 最折腾，放最后。

## 五步上手

1. **装软件（约 30 分钟）：** 看 [docs/02_安装软件.md](docs/02_安装软件.md)。每一步都有一条命令检查装好没有。
2. **装 Claude Code 并登录：** 看 [docs/03_安装Claude_Code.md](docs/03_安装Claude_Code.md)。
3. **申请配音的 API Key，填进 `.env`：** 看 [docs/04_账号和密钥.md](docs/04_账号和密钥.md)。
4. **在这个仓库目录里打开 Claude Code，对它说：**
   ```
   我想拍一部 3 分钟左右的横屏短片，发抖音，主题是「……」。
   按 CLAUDE.md 的流程带我做，先帮我检查环境。
   ```
5. **跟着它走：** 它每一步都会告诉你要做什么、给你看什么。怎么提意见最有效，看 [docs/05_跟AI沟通.md](docs/05_跟AI沟通.md)。

> `CLAUDE.md` 是写给 AI 看的「导演手册」，Claude Code 在这个目录里启动时会自动读取它。你不用读懂它，但知道它在那儿就好。
